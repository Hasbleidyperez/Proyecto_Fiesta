# Proyecto_Fiesta
# Planificación de una Fiesta - Analogía de Ingeniería de Software

## Integrantes
- Hasbleidy Pérez Giraldo

## Descripción
Este proyecto utiliza la organización de una fiesta para explicar las fases de la Ingeniería de Software, incluyendo planificación, gestión, validación y seguimiento.

## Objetivo
Aplicar conceptos de gestión de proyectos e ingeniería de software mediante una analogía de la vida cotidiana.
